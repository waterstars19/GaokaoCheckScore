# GoakaoProject — 高考志愿填报系统

## 项目简介
面向河南考生的 AI 志愿填报推荐系统，基于 2017-2025 年录取数据，
提供分数查询、院校推荐、录取概率、选科建议等功能。

## 技术栈
- 后端: Python + FastAPI (Uvicorn)
- 前端: HTML + JavaScript (原生)
- 数据: JSON 文件存储

## 快速启动
```bash
cd backend
python app.py
```
访问 http://localhost:8000

## 核心功能
- 📊 **标准化排位分**: 历年分数统一映射到 0~1,000,000，跨年份可比
- 🎯 **冲稳保推荐**: 基于区间重叠算法，合理分配 64 个志愿
- 🏷️ **专业标签**: 19 类专业标签 + 数据驱动热度分析
- 🎨 **艺体推荐**: 8 个艺术/体育类别，按概率排序
- 🔍 **多维度筛选**: 省份、专业类别、选科要求、标签
- ⚙️ **策略选择**: 冲击型 / 均衡型 / 稳妥型 / 自动

## 数据来源
- 河南省教育考试院官方录取数据（2017-2025）
- 教育部阳光高考平台
- 各高校招生章程
- 第四轮学科评估
- 软科中国大学排名
