# 河南高考志愿推荐系统 🦀

基于标准化排位分算法的新高考志愿填报辅助系统，支持 **冲稳保推荐**、**艺体推荐**、**专业标签筛选**。

## 快速启动

```bash
cd backend
python app.py
```

然后访问 `http://localhost:8000`

## 功能

- 📊 **标准化排位分**：将历年分数统一映射到 0~1,000,000 空间，跨年份可比
- 🎯 **冲稳保推荐**：基于区间重叠算法，合理分配 64 个志愿
- 🏷️ **专业标签**：19 类专业标签 + 数据驱动热度分析
- 🎨 **艺体推荐**：8 个艺术/体育类别，按概率排序
- 🔍 **多维度筛选**：省份、专业类别、选科要求、标签
- ⚙️ **策略选择**：冲击型 / 均衡型 / 稳妥型 / 自动

## 数据源

- 河南省教育考试院官方录取数据（2017-2025）
- 一分一段表 + 录取统计 + 招生计划
- 涵盖一本、二本、高职高专全部批次

## 技术栈

- **后端**：Python FastAPI
- **前端**：纯 HTML/CSS/JS（单页面应用）
- **算法**：标准化排位分 + 区间重叠匹配
