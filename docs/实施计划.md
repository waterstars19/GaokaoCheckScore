## 一、算法公式

### 1.1 标准化排位分

```
给定某年总考生数 N，某位次 rank（1-based）：
  
  标准化排位分 = round( ln(N / rank) / ln(N) × 1,000,000 )

范围：0 ~ 1,000,000
  状元（rank=1）      → 1,000,000
  中间（rank=N/2）   → ln(2)/ln(N) × 10⁶ ≈ 50,217
  最后一名（rank=N） → 0
```

### 1.2 考生区间计算

```
对于分数 score，根据一分一段表：
  同分人数 = count[year][cat][score]
  累计人数 = cumulative[year][cat][score]   ← 该分数最低排名
  
  最高位次 = cumulative - count + 1         ← 同分中最佳排名
  最低位次 = cumulative                      ← 同分中最差排名

考生标准化区间 = [标准化(最低位次), 标准化(最高位次)]
                 ↑ 最差情况                  ↑ 最好情况
```

### 1.3 学校/专业区间计算

```
对于某校某专业历年录取数据：
  最高录取位次 = min(所有录取学生的位次)  ← 门槛最高
  最低录取位次 = max(所有录取学生的位次)  ← 门槛最低

标准化区间 = [标准化(最低录取位次), 标准化(最高录取位次)]
```

### 1.4 冲稳保判定

```
考生区间 = [S_low, S_high]
学校区间 = [T_low, T_high]

重叠量 = max(0, min(S_high, T_high) - max(S_low, T_low))

判定：
  S_high < T_low + margin → 🔼 冲（有一定差距）
  S_low > T_high - margin → 🔽 保（有一定余量）
  有重叠 → ✅ 稳
  远低于 → ❌ 不可能
  远高于 → 💸 浪费分数
```
