# 志愿查询系统 · 维度设计报告

## 一、概述

在推荐系统（根据分数自动推荐冲稳保）之外，新增一个**查询系统**，让用户可以像逛淘宝一样，多维度自由筛选院校和专业，找到心仪的目标后再加入志愿表。

## 二、查询维度总览

### 第一层：必选筛选（3个）

| 维度 | 类型 | 说明 | 数据来源 |
|------|------|------|---------|
| **年份** | 下拉 | 2017~2025 | 已有 |
| **科类** | 下拉 | 物理类 / 历史类 | 已有 |
| **查询目标** | 选项卡 | 院校查询 / 专业查询 / 专业组查询(2025) | 三种视图 |

### 第二层：精准定位（8个）

| 维度 | 类型 | 说明 |
|------|------|------|
| **院校名称** | 输入框+自动补全 | 输入关键词模糊搜索 |
| **院校代码** | 输入框 | 精确匹配 |
| **专业名称** | 输入框+自动补全 | 输入关键词模糊搜索 |
| **专业组代码** | 输入框 | 仅2025年生效 |
| **省份** | 下拉 | 33省+其他，已有 |
| **录取批次** | 多选 | 一本 / 二本 / 高职高专 / 全部 |
| **院校层次** | 多选 | 985 / 211 / 双一流 / 省重点 / 普通 |
| **办学性质** | 多选 | 公办 / 民办 / 中外合作 |

### 第三层：分数/位次筛选（3个）

| 维度 | 类型 | 说明 |
|------|------|------|
| **最低分区间** | 滑块输入 | 原始分范围，如 400~600分 |
| **最高分区间** | 滑块输入 | 可选，用于控制录取分范围 |
| **位次区间** | 区间输入 | 省排名范围，如 50,000~100,000 |

### 第四层：附加筛选（4个）

| 维度 | 类型 | 说明 |
|------|------|------|
| **专业类别** | 下拉 | 10大类，已有 |
| **专业标签** | 多选 | 19个标签，已有 |
| **选科要求** | 多选 | 仅2025年生效，已有 |
| **同位分换算** | 显示 | 自动换算用户输入分数到其他年份 |

### 第五层：录取趋势参考（2个）【进阶功能】

| 维度 | 类型 | 说明 |
|------|------|------|
| **近3年波动** | 显示标记 | 该专业近3年录取分涨跌幅（↑稳定/↑↑上涨/↓↓下跌） |
| **大小年预警** | 显示标记 | 录取分隔年波动大的专业标记 ⚠️ |

### 三种查询视图

#### 📚 院校视图
按学校聚合展示，每所学校展开后显示该学校的所有专业录取信息
- 列表：院校名称 | 省份 | 层次 | 批次 | 最低录取标准分 | 标签
- 点击展开：该院校下所有专业/专业组的录取数据

#### 📖 专业视图
按专业聚合展示，显示同一专业在不同学校的录取对比
- 列表：专业名称 | 院校名称 | 各省录取分 | 近3年趋势 | 标签
- 支持同专业跨校横向对比

#### 📋 专业组视图（2025+）
展示院校专业组模式下的所有专业组数据
- 列表：院校名称 | 专业组代码 | 组内专业 | 选科要求 | 录取标准分

## 四、结果展示

### 表格列（可配置显示）
- 序号
- 院校名称（含层次标记 🏅985/⭐211/📌双一流）
- 院校代码
- 专业名称 / 专业组代码
- 省份
- 批次
- 最低录取分（原始分）
- 最低位次
- 录取概率（如果用户输入了分数）
- 近3年趋势 📈📉
- 操作：加入志愿表、查看详情

### 排序方式
- 按录取分（高→低 / 低→高）
- 按位次
- 按年份
- 按概率（需用户输入分数）

### 导出
- 当前筛选结果导出为 CSV
- 选中项批量加入志愿表

## 五、API 设计

```
GET /api/query-schools
  ?year=2024
  &category=文科
  &school=南京邮电          # 院校模糊搜索
  &major=计算机             # 专业模糊搜索
  &province=江苏            # 省份筛选
  &batch=一本               # 批次筛选
  &level=211                # 院校层次筛选
  &nature=公办              # 办学性质
  &score_min=500            # 最低分下限
  &score_max=600            # 最低分上限
  &rank_min=10000           # 位次下限
  &rank_max=50000           # 位次上限
  &major_category=计算机    # 专业类别
  &tags=高薪技术            # 专业标签
  &sort=score_desc          # 排序方式
  &page=1
  &page_size=50
```

## 六、数据依赖分析

| 维度 | 是否已有数据 | 缺失的数据 | 获取方式 |
|------|------------|-----------|---------|
| 省份 | ✅ | - | 已有 school→province |
| 批次 | ✅ | - | pro模型已提取 |
| 院校层次 | ❌ | 985/211/双一流标记 | 需外部数据（可手动标List: 39所985+112所211）|
| 办学性质 | ❌ | 公办/民办区分 | 需外部数据 |
| 院校代码 | ✅ | - | 已有 |
| 近3年波动 | ✅ | - | 可计算：对比同专业历年标准分 |
| 大小年预警 | ✅ | - | 可计算：检测隔年标准分波动 |
| 同位分换算 | ✅ | - | 已有 isotonic 函数 |
