| 跨省批次线 | 无 | 缺 31 省 2008-2020 数据 |

**本地的可用源数据：**
- `D:\GoakaoProject\批次线与参考\河南_省控线_批次线_2022_2014.xlsx` → 9 年（2014-2022）河南批次线，含文/理科分开、含体育类线

**影响范围：**
- app.py 的 `/api/recommend` 未使用 batch_lines.json（推荐算法不检查批次资格）

- 前端没有批次线参照展示

**建议：** 将 `河南_省控线_批次线_2022_2014.xlsx` 和 `2008-2020各省-批次线.xlsx` 全部解析导入 `batch_lines.json`，并在推荐 API 中增加批次资格校验逻辑。

**建议：** 将 45,892 条选科要求表解析为 `subject_requirements.json`，关联到 admission_plans；补充 major_details 的 subject_suggest 字段。

## 6. 推荐系统算法数据完整性

### 6.1 冲稳保算法数据流

```
user_score → standardized_scores.json → s_low, s_high (学生区间)
                                         ↓
MAJOR_STD (旧高考) 或 GROUP_STD (新高考) → t_low, t_high (目标区间)
                                         ↓
_score_match() → tier (chong/wen/bao) + rel_pos + confidence
                                         ↓
_format_prob() → probability (1%-98%)
```

### 6.2 现有数据 → 算法需求匹配

| 数据需求 | 数据文件 | 覆盖率 | 注 |
|:---------|:---------|:------|:---|
| 学生分→排位→标准化分 | standardized_scores.json | 100% (2017-2025) | ✅ |
| 专业历史录取区间 | major_standards.json | 198K 条 | ✅ |
| 学校历史录取区间 | school_standards.json | 33K 条 | ✅ |
| 2025 专业组预估 | group_standards.json | 6,846 组 | ✅ |
| 批次资格线 | batch_lines.json | 仅 2025 | 🔴 缺 2017-2024 |
| 招生计划数 | admission_plans.json | 538K 条 | ✅ 有但未在算法中使用 |
| 选科要求 | group_majors.json | 仅 2025 组级别 | 🔴 缺专业级 |
| 一分一段查分 | score_distribution | 仅 2025 | 🔴 缺历年 |

### 6.3 算法中使用但数据缺失的功能

1. **批次资格校验** → batch_lines.json 不完整，算法不检查
2. **选科反向推荐** → 无 "用户选科组合 → 可报专业列表" 功能
3. **同位分换算** → 当前 `/api/query` 已实现，但仅在同一年分数的 ±10000 排位范围内查询
4. **招生计划利用率分析** → 有 plan_count 但未展示给用户（如 "计划招15人，往年录取概率如何"）
