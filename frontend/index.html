📐 算法原理说明

一、核心问题

高考分数在不同年份的含金量不同——试卷难度、考生人数、分数线都在变。
2024年的600分和2020年的600分不可直接比较。
我们的算法将历年分数统一映射到 0 ~ 1,000,000 的标准化排位分空间，实现跨年份可比对。

二、排位标准分计算公式

标准分 = ln(N / rank) / ln(N) × 1,000,000
  • N = 当年该科类总考生人数（如2024年理科约60万）
  • rank = 考生的省排名（位次）
  • ln() = 自然对数

为什么用对数？因为位次越靠前，每前进一名越难。对数变换将这种非线性关系线性化。

🟢 示例：
2024年理科610分，位次约 17,000 名，总考生 600,000 人
标准分 = ln(600,000 / 17,000) / ln(600,000) × 1,000,000
= ln(35.29) / ln(600,000) × 1,000,000
= 3.564 / 13.305 × 1,000,000 ≈ 267,000

三、区间化处理

同一分数可能对应多名考生（如600分有500人同分），导致位次是一个范围而非单点。

学生区间： 分数 → 最低位次 ~ 最高位次 → 最低排位分 ~ 最高排位分
院校/专业组区间： 该专业/专业组录取的全部学生的成绩范围

我们用区间重叠度来计算匹配程度，而非简单的"分数线过了没"。

四、匹配算法（冲稳保判定）

令 s_mid = 学生区间的中点，t_center = 目标区间的中点
t_radius = (目标区间宽度) / 2
rel_pos = (s_mid - t_center) / t_radius
rel_pos < -1 → 冲（学生排位分低于目标）
-1 ≤ rel_pos ≤ 1 → 稳（学生排位分在目标范围内）
rel_pos > 1 → 保（学生排位分高于目标）

五、概率映射

档次rel_pos 范围概率范围说明
冲-3 ~ -11% ~ 30%排位分低于目标，但差距不大时可以尝试
稳-1 ~ 130% ~ 70%排位分在目标区间内，录取概率较高
保1 ~ 370% ~ 98%排位分明显高于目标，作为保底

概率由 rel_pos 在档内的相对位置线性插值得到。越靠近目标区间中心，概率越高。

六、推荐数量分配

冲：10 个  |  稳：30 个  |  保：24 个  =  64 个志愿

对应2025年新高考最多64个志愿的填报策略。

  • 冲：按与目标的"最近距"排序，取最接近的10个
  • 稳：按"居中程度"排序（|rel_pos|最小），取最居中的30个
  • 保：按与目标的"最近距"排序（从上方），取最接近的24个
